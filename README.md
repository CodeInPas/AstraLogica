# AstraLogica: Orbital Command

> *A retro-themed orbital command simulation game built with Lazarus, Free Pascal, and BGRABitmap.*

## 🛰️ About The Game

**AstraLogica: Orbital Command** is a tactical retro-tech sci-fi simulation where you act as the Chief Operations Officer (COO) of an isolated space station. Your mission is simple yet brutal: **Survive 14 Sol cycles** against cosmic anomalies, power blackouts, reactor meltdowns, and mysterious deep space transmissions.

## ⚡ Key Features

* **Retro-Tech Aesthetic:** Authentic CRT scanlines, visual filters (CRT Glitch, Red Alert, Starfield), and dynamic EKG-style core trace graphs.
* **Resource Management:** Balance oxygen levels, power reserves, hull integrity, and core temperature to prevent total station collapse.
* **System Modules & Crew Allocation:** Toggle, upgrade, and assign crew members to operational systems like Life Support, Deflector Shields, and Research Labs.
* **Deep Space Encounters:** Intercept unknown radio transmissions and make high-risk, high-reward decisions under strict time limits (`T-15s`).
* **Crisis Management:** Survive solar flares and meteor showers using emergency directives or dispatching repair drones.

## 🛠️ Built With

* **Language:** Object Pascal (Free Pascal)
* **IDE:** Lazarus
* **Graphics Library:** BGRABitmap
